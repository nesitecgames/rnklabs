Sebelum Anda mulai

Siapkan PDF dan pilih folder tempat Anda dapat menemukan gambar yang diekspor. Setiap halaman PDF yang dipilih menjadi gambar. Tangkapan layar aplikasi menggunakan konten demo tanpa data pribadi. Label pemilih file Android mungkin berbeda menurut perangkat dan bahasa.

LANGKAH 01/04

Pilih PDFnya

Buka PDF ke Gambar pada Alat. Ketuk Pilih PDF dan pilih dokumen sumber.

LANGKAH 02/04

Pilih halaman dan format gambar

Gunakan kotak centang halaman untuk memilih halaman individual atau pilih Pilih semua halaman. Pada Opsi Keluaran, pilih JPG atau PNG. Aktifkan Buat ZIP jika Anda ingin keluarannya dikemas bersama.

LANGKAH 03/04

Pilih folder keluaran

Ketuk Simpan ke folder. Di pemilih folder Android, pilih tujuan dan konfirmasikan akses ke folder itu bila diminta. Biarkan ekspor selesai sebelum keluar dari aplikasi.

LANGKAH 04/04

Periksa gambar yang diekspor

Buka folder tujuan di pengelola file Anda. Periksa apakah Anda memiliki halaman yang diharapkan dan teks dapat dibaca. Jika Anda mengaktifkan keluaran ZIP, buka atau ekstrak arsip untuk mengakses gambar di dalamnya.

Tips untuk hasil yang lebih baik

  • JPG berguna untuk halaman fotografi; PNG berguna untuk menjaga kualitas grafis yang tajam.
  • Periksa pilihan halaman Anda sebelum mengekspor untuk menghindari file yang tidak diperlukan.
